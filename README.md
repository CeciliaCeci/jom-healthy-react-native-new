## Operating Mode 
```bash
cd jomhealthy-react-native
npm install
npx expo start
```

Then scan the code with Expo Go, or press `a` to run the Android emulator, and press `i` to run the iOS simulator. 
## Main Contents 
```text
src/
components/      General components and pop-up windows
context/         Language, child information and dietary status
navigation/      React Navigation routes
screens/         App pages
theme/           Color theme
assets/imports/  Image resources ```
